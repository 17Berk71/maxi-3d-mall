# Запуск MVP бесплатно, без домена

Идея: пока проект показываем узкому кругу (друзьям, магазинам, администрации), домен и платный хостинг не нужны. Сайт — просто папка файлов `dist/`, её можно положить куда угодно.

## Что уже готово в коде
- Three.js и все шрифты лежат в самой сборке (`npm run build`): ни cdnjs, ни Google Fonts не нужны. Для России это важно — внешние сервисы нередко недоступны.
- Пути относительные (`base: './'`): сайт работает и в корне адреса, и во вложенной папке (`…/bucket/index.html`).
- Выгрузки товаров лежат в `public/feeds/` и попадают в `dist/feeds/`; фото неизменяемые (имя = хеш), страница и JSON всегда проверяются заново.
- `noindex` и `robots.txt` с запретом: поисковики сайт не покажут, пока не снимем (см. «Когда выходим в открытый показ»).
- «О проекте»: неофициальный проект, товарные знаки принадлежат владельцам, планировка приблизительна, личных данных не собираем, строка «Для правообладателей: напишите…» — появляется, если задать `VITE_CONTACT` в `.env` (пример — `.env.example`).
- Скрипт выгрузки `npm run deploy` (сборка + загрузка в Яндекс Object Storage с правильными типами файлов). Проверка без загрузки: `npm run build && npm run deploy:dry`.

## Вариант A (рекомендую): Яндекс Object Storage, бесплатный адрес
1. Зарегистрироваться в Яндекс Облаке и создать платёжный аккаунт (нужна карта, но при небольшом объёме списаний нет; бесплатные лимиты уточни на странице тарифов — они меняются). Поставить уведомление о бюджете, например 100 ₽.
2. Создать бакет, имя например `tula-mall-walk` (**без слова «maxi»**, чтобы не нарушать чужой товарный знак). Доступ на чтение объектов — публичный.
3. Включить в бакете «Веб-сайт»: главная страница `index.html`, страница ошибки `404.html`.
4. Создать сервисный аккаунт с ролью `storage.editor`, выпустить статический ключ, выполнить `aws configure` (регион `ru-central1`).
5. `YC_BUCKET=tula-mall-walk npm run deploy`.
6. Адреса, которые получатся бесплатно:
   - `https://storage.yandexcloud.net/tula-mall-walk/index.html` — работает по HTTPS, сразу;
   - `http://tula-mall-walk.website.yandexcloud.net` — короче, но HTTP (HTTPS на этом адресе — только со своим доменом и сертификатом).
   Для показа лучше первый. Телефону HTTPS не обязателен, но ссылка выглядит надёжнее.
7. Обновление сайта — та же команда. `--delete` убирает из бакета старые файлы.

## Вариант B: ещё проще, вообще без регистрации
- Для показа на встрече: `npm run build && npm run preview` и открыть на ноутбуке, либо опубликованная страница-артефакт Claude (ссылка уже есть, но она содержит упрощённую сборку и не покажет папку `feeds/` целиком).
- Любой российский хостинг со статикой (Beget, Timeweb, REG.RU) — тоже просто загрузить содержимое `dist/`. Плюс — часто есть бесплатный поддомен вроде `имя.beget.tech`.
- Зарубежные GitHub Pages, Cloudflare Pages, Vercel, Netlify для российских посетителей работают нестабильно, на них MVP не строим.

## Что платить и когда
| Этап | Что нужно | Цена |
|---|---|---|
| Сейчас, показ своим | бесплатный адрес бакета | 0 ₽ |
| Показ магазинам и администрации | домен `.ru` в Beget или REG.RU, привязка к бакету, бесплатный сертификат Let's Encrypt в Облаке | около 200–400 ₽ в год |
| Реальные товары | выгрузки партнёрских сетей (Admitad и т. п.), каждая сеть подключается отдельно | 0 ₽ (комиссия идёт с продаж) |
| Заказы и брони прямо в проекте | небольшой бэкенд (Облачные функции, около 1 млн вызовов в месяц бесплатно) | 0 ₽ на старте |

Домен: короткий и нейтральный, например `tula-walk.ru` или `галерея-тула.рф`. Слово «maxi» в названии домена не используем — риск претензии по товарному знаку.

## Когда выходим в открытый показ
1. Убрать `noindex` из `index.html` и заменить `robots.txt` на разрешающий (`Allow: /`).
2. Получить хотя бы устное согласие администрации ТРЦ. Без него — оставить подпись «неофициальный концепт», не использовать логотипы и фирменные цвета, быть готовым быстро убрать по просьбе (контакт для связи — `VITE_CONTACT`).
3. Подключить домен и сертификат.
4. Добавить счётчик посещений (Яндекс Метрика), если нужна статистика; тогда в «О проекте» убрать фразу «не собирает личных данных» и написать про счётчик.

## Проверка перед каждым выкладыванием
1. `npm run check` (нужен запущенный `npm run dev`) — оба этажа, двери, магазины, корзина, телефон.
2. `npm run build` и `npm run preview` — посмотреть, как открывается собранная версия, особенно шрифты вывесок.
3. Открыть адрес с телефона через мобильный интернет, а не через Wi-Fi дома.
4. Проверить, что фото в `feeds/` открываются (в консоли браузера нет 404 и ошибок типа файлов).
