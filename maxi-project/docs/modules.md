# Карта модулей сайта

Создано `node tools/docs/modules.mjs > docs/modules.md` — обновляй после переноса или добавления модулей.
Как устроено и где что менять — `docs/architecture.md`.

## Входные файлы

- `app.js` (3.9 КБ) — Основное приложение: галерея ТРЦ, управление, магазины изнутри. Сам код — в модулях по папкам (core, render, nav, mall, controls, ui, shop; карта — docs/modules.md). Здесь только запуск: параметры (данные карты обоих этажей) и init() модулей строго по порядку — порядок важен: модуль может использовать то, что подготовили модули выше.
  - отдаёт: `D`, `startApp`, `D2`
- `main.js` (0.8 КБ) — Точка входа Vite: шрифты, стили, данные карты обоих этажей → startApp (app.js).

## controls — игрок, камера, ввод

- `controls/input.js` (7.7 КБ) — Ввод: захват мыши, мышь, касания, щипок, джойстик, клавиатура.
  - отдаёт: `ptrs`, `requestLock`, `releaseLock`, `isFP`, `panelsClosed`, `updateCross`, `clampH`, `locked`, `lockFailed`, `mouse`, `SENS_BASE`
- `controls/move.js` (2.4 КБ) — Ходьба: джойстик, столкновения со стенами, смена этажа.
  - отдаёт: `updateJoy`, `blockedF`, `blocked`, `tryMove`, `setFloor`, `updateFloorUI`, `goFloor`
- `controls/player.js` (1.7 КБ) — Игрок и камера: положение, режим (прогулка, сверху, магазин), позы камеры, режим без анимации.
  - отдаёт: `player`, `walkPose`, `topPose`, `applyPose`, `topv`, `keys`
- `controls/view.js` (2.2 КБ) — Вид сверху: вписать здание, какой этаж показывать, переключение режима.
  - отдаёт: `bb`, `setVis`, `topY`, `setMode`

## core — запуск, цикл, общее состояние, настройки

- `core/debug.js` (2.6 КБ) — Отладочный доступ для тестов: window.__maxi (страница с ?debug).
- `core/fonts.js` (0.6 КБ) — Шрифты лежат в самой сборке (пакеты @fontsource), с Google Fonts ничего не подгружается: сайт работает без внешних сервисов, которые в России могут быть недоступны.
- `core/helpers.js` (0.3 КБ) — Мелкие помощники: $ (элемент по id), V3, LIN (цвет sRGB → линейный).
  - отдаёт: `$`, `V3`, `LIN`
- `core/launch.js` (0.2 КБ) — Старт приложения.
- `core/loop.js` (6.3 КБ) — Главный цикл: кадр (frame → frameBody в try/catch), обновление всех систем.

- `core/state.js` (1.6 КБ) — Общее изменяемое состояние галереи: только то, что меняют разные модули. Читать и писать — app.имя. Всё остальное модули берут друг у друга через import (функции, константы, переменные-владельцы).   curFloor     — текущий этаж (1 | 2)   mode         — 'walk' (прогулка) | 'top' (вид сверху) | 'store' (в зале магазина)   anim         — текущий перелёт камеры (moveTo) или null   filter       — выбранная категория в фишках или null   target       — выбранный магазин (карточка) или null   ride         — поездка: лифт {kind:'lift'…} или эскалатор {kind:'esc'…}, иначе null   joyV         — вектор джойстика на телефоне {x, y, run}   calm         — режим без анимации   lookDX/lookDY — накопленный поворот взгляда от мыши/пальца (тратится в кадре)   FOGW         — туман (меняют стили оформления)   SHOP         — текущий зал магазина {s, scene, …} или null; SHOP_PEOPLE — покупатели в нём   shopDept, shopProd — открытый отдел и товар в панели магазина   PS           — откуда каталог в панели: зал (SHOP) или островок {s, cat}
  - отдаёт: `app`
- `core/utils.js` (0.8 КБ) — Общие мелочи: детерминированный генератор случайных чисел (mulberry), осветление/затемнение цвета (shade).

## render — рендер галереи, текстуры, эффекты

- `render/canvas.js` (0.8 КБ) — Текстуры из canvas: canvasTex (sRGB), скруглённый прямоугольник, подбор размера шрифта.

- `render/floor-mirror.js` (2.3 КБ) — Отражение пола без второго прохода рендера (зеркальная копия первого этажа).
  - отдаёт: `buildFloorMirror`
- `render/fx.js` (13.2 КБ) — Эффекты картинки: отражения в полу, свечение ламп и вывесок, цветокоррекция и виньетка. Качество выбирается само по замеру времени кадра: уровень 0 (без эффектов) … 3 (полный). Телефон стартует с 1, компьютер с 3; если кадры тяжёлые — уровень падает, если есть запас — растёт (уровень, на котором было тяжело, больше не включается). Для проверки: ?q=0..3 фиксирует уровень. На телефоне живого отражения нет никогда: вместо него «поддельный» блеск — пол отражает снимок окружения (кубическая карта 6×128 px вокруг игрока, по одной грани за кадр, обновляется, когда отошёл на 10 м). Режимы для настроек: setMode('auto' | 'best' | 'fast').
  - отдаёт: `makeFX`
- `render/merger.js` (3.0 КБ) — Склейка тысяч квадов и мешей в несколько больших BufferGeometry (Merger), формы, выдавливание.
  - отдаёт: `Merger`, `shapeOf`, `extrude`, `flatShape`
- `render/resize.js` (0.4 КБ) — Размер окна изменился — рендер, камера, мини-карта.
