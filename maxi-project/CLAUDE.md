# CLAUDE.md — Прогулка по Макси

Неофициальный 3D-концепт ТРЦ «Макси» (Тула), два этажа. Цель — посетитель, который не может прийти лично, гуляет по галерее, заходит в магазины, смотрит товары и оформляет заказ (демо). Пользователь общается по-русски. Весь текст интерфейса тоже на русском, простым языком, без канцелярита.

## Команды

- `npm run dev` — dev-сервер Vite на http://localhost:5173.
- `npm run check` — проверка в браузере через Playwright (нужен запущенный `npm run dev`). Проходит сценарии: оба этажа, вид сверху и «Перейти сюда», лифт, Спортмастер, кино, фуд-корт, товар на манекене, корзина и заказ, режим без анимации, телефон вертикально и горизонтально. Скриншоты сохраняются в `tools/test/out/`, при ошибках на странице или несработавшем сценарии выход с кодом 1. Если Playwright не находит браузер — `CHROME_PATH=... npm run check` (в облаке Claude Code берётся `/opt/pw-browsers/chromium` сам). Сбой загрузки Google Fonts не считается ошибкой. **Запускай после каждого заметного изменения и смотри скриншоты.** Логические тесты без отрисовки однажды пропустили баг, из-за которого внутри магазина был белый экран.
- `npm run build` — сборка в `dist/`.
- `npm run map` — пересобрать `src/data/maxi-data.json` из скриншотов (Python, см. `tools/pipeline/requirements.txt`).
- Страница с `?debug` открывает `window.__maxi` (mode, player, S, SHOP, keys, enterShop, exitShop, openProduct, walkToDoor, walkTo, setMode, blocked, isWalk, loaded, floor, anim, setFloor, goFloor, lifts, startRide, ride, cart, openCart, setCalm, calm, topTap, topv, openLiftPanel, showTop). `?calm=1` — режим без анимации. Используй это в тестах, чтобы телепортироваться и проверять состояния.

## Стек и важные ограничения

- Three.js **закреплён на 0.128.0**. Код использует `renderer.outputEncoding = THREE.sRGBEncoding`, `texture.encoding`, `physicallyCorrectLights`, `InstancedMesh.setColorAt`. Переход на новую версию требует замен: `outputColorSpace`/`colorSpace`, `THREE.SRGBColorSpace`, убрать `physicallyCorrectLights`, пересмотреть интенсивность света, `LIN()` → `Color.convertSRGBToLinear` уже не нужен при `ColorManagement`. Делать это отдельной задачей и сверять скриншоты «до/после».
- Цвета материалов и вершин задаются через `LIN('#hex')` (перевод sRGB → линейный). Текстуры с canvas — через `canvasTex()`, у них стоит sRGB.
- Шрифт Manrope с Google Fonts. Canvas-тексты ждут `document.fonts.load` перед сборкой сцены.

## Архитектура (`src/app.js`, функция `startApp(D)`)

Сейчас это один большой модуль с общим замыканием. Разделы по порядку:

1. **Сетка проходимости** — своя у каждого этажа: `GRIDS[1]` из `D.grid` (битовая маска 0.316 м/клетка), `GRIDS[2]` — те же коридоры без проёмов (`voids`). `isWalkF(f,x,z)`, `blockedF(f,x,z)` (радиус игрока 0.35 м), `isFloorF` (исходная маска без дверей), `setRect/blockRect(...,f)` правят маску этажа (проёмы дверей, эскалаторы, колонны, лифты), `nearestFree(x,z,r,f)`. Без `f` — текущий этаж `curFloor`.
2. **Категории и данные**: `CATS`, массив `S` — помещения и островки из `D.stores`/`D.kiosks` (floor 1) и помещения второго этажа из `floor2Of()` в `src/floor2.js` (floor 2); у каждого `id`, `floor`, `name`, `cat`, `what`, `col` (линейный), `colHex`.
3. **Рендер**: ACES, sRGB, окружение из PMREM (светлый зал), небо, туман.
4. **Merger** — склейка тысяч квадов и мешей в несколько больших BufferGeometry. `quad(a,b,c,d,uv,color,sid)`: a — низ-лево, b — низ-право (как видит зритель со стороны лицевой грани). `panel(center,n,w,y0,y1,...)` — вертикальная панель, лицом к нормали `n`. **Вывески делай через `panel`**: однажды текст был зеркальным из-за неверного порядка вершин.
5. **Текстуры и атласы**: полки витрин по категориям, вывески (512×64 на магазин в атласах 2048²), подписи для вида сверху.
6. **`build()`** — вся галерея: пол-мрамор, полосы у проёмов, `fronts(FLOORS[f], список)` для каждого этажа (крыша для вида сверху, витрины, интерьер за стеклом, промо-плакаты `POSTERS`, двери, вывески, манекены), двери (`world.doorSets` — отдельно на каждом этаже), перекрытие и пол второго этажа, крыша, ограждения, колонны, светильники, фасад и входы, эскалаторы, инфо-колонны островков, лифты (`world.lifts`, места из `LIFTS_PLAN`), посетители обоих этажей, колесо обозрения.
   Группы сцены: `stores` (1 этаж), `f2` (2 этаж), `slab` (перекрытие, пол 2 этажа, ограждения), `roof` (крыша, колонны, светильники), `spots`, `shell`, `people`, `toplabels1/2` и `toponly1/2` (только в виде сверху). `setVis()` показывает в виде сверху один этаж: для первого прячет `slab`/`f2`/`roof`, для второго — `roof`.
7. **Управление**: `player {x,z,yaw,pitch,vx,vz}`, `curFloor`, режимы `mode = 'walk' | 'top' | 'store'`. Уровни пола `FY[f]`, высота глаз `eyeY()`. `moveTo(f,x,z,yaw)` переносит в точку любого этажа (с затемнением при смене этажа), `setFloor(f)`, `goFloor(f)` — кнопки «1/2» и клавиши 1/2. Лифт: панель `#lift` открывается у дверей (`updateLifts`), поездка `ride` по фазам в `updateRide` идёт по реальному времени (`rawDt`), а не по ограниченному `dt`. Pointer lock: клик по сцене захватывает курсор, открытие окна его освобождает, закрытие снова захватывает (`requestLockIfNeeded`). Ошибка захвата **не** выключает режим навсегда (`lockErrors`, запасной режим только после 3 ошибок подряд). Поза камеры: `mode==='top' ? topPose() : walkPose()`. Магазин — тоже режим от первого лица.
8. **Выбор**: raycast по `pickables`. Id объекта берётся из `userData.fs[faceIndex]` (склеенные меши) или `userData.kiosks[instanceId]` (инстансы).
9. **Карточка, фильтр, поиск, мини-карта текущего этажа (лифты, эскалаторы), «Перейти сюда» в виде сверху (`topTap`), подсказки.** Режим без анимации `calm` (системная настройка, переключатель в «О проекте», `?calm=1`): перелёты, двери, лифт и затемнения — сразу, люди и колесо стоят.
10. **Цикл**: `frame` → `frameBody` в try/catch, чтобы ошибка не замораживала страницу.
11. **Магазины изнутри** (после цикла): `models()` — простые 3D-модели товаров, `buildShop(s)` — отдельная `THREE.Scene` зала (отделы по сетке, стеллажи, вешала, манекены, примерочные, корзины, касса, покупатели, дверь с видом на галерею). Вход и выход **бесшовные**: `enterShop(s,{along,lat})` и `exitShop({along,lat})` переносят позицию и направление взгляда относительно двери. Страница товара `openProduct` — отдельный маленький WebGL-рендерер для 3D-просмотра, режим «на манекене», размеры, рейтинг, наличие, «В корзину» / «Купить сейчас», плашка «Описание» и «Характеристики» (`src/shop/describe.js`). Корзина — `src/shop/cart.js` (localStorage), окно `#cartBox` с формой заказа (демо, никуда не отправляется). У кинотеатра в зале афиши и двери залов.

Отделы, демо-товары и ссылки на сайты — `src/shop/catalog.js` (`BY_NAME` — отделы конкретных магазинов). Ссылки на сайты добавляй только проверенные: иначе остаётся поиск на Яндекс Картах. Картинки карточек — `src/shop/icons.js`.

### Координаты

Метры. `x` — на восток, `z` — на юг (как на Яндекс Картах: север сверху), `y` — вверх. Пол первого этажа 0, перекрытие `FLOOR_H = 8.6`, витрины `GLASS_H = 5.0`, рост глаз `EYE = 1.65`. В зале магазина начало координат в центре комнаты, дверь на `z = D/2`, нормаль наружу `+z`.

### Формат `src/data/maxi-data.json`

- `grid {W,H,cell,x0,z0,b64}` — маска проходимости (packbits, base64).
- `bld` — контур здания; `voids` — проёмы галереи второго этажа; `cols` — колонны.
- `stores[] {name, names[], cat, what, poly[[x,z]], area, c, lp, fit}`: `lp` — точка подписи, `fit` — размер подписи для разных пропорций текста (для вида сверху).
- `kiosks[] {name,cat,what,p,w,h,a}` — островки (в 3D это инфо-колонны, сквозь них можно пройти).
- `esc[] {p,a}` — эскалаторы (центр, направление подъёма); `ents[] {n,p,d}` — входы с направлением наружу.

### Второй этаж (`src/floor2.js`)

Точной схемы второго этажа в открытых источниках нет. Помещения повторяют контуры первого этажа, кроме гипермаркетов в два этажа (`TALL`); над Мисти Парком — Синема Парк, фуд-корт — ближайшее к кино большое помещение, остальные настоящие арендаторы (`TENANTS`, по 2ГИС и сайту ТРЦ) раскладываются по площади. Лифты — по значкам на `tools/pipeline/source/plan.png`, пересчитаны в метры по опорным точкам конвейера (Кофе культ, входы 3–5), погрешность около 5 м; в сцене лифт ставится рядом у стены. Когда появятся скриншоты второго этажа с Яндекс Карт — заменить раскладку конвейером.

## Конвейер карты (`tools/pipeline`)

`run.sh` по шагам: `ex.py`/`ex2.py` (контур по схеме ТРЦ) → `mosaic.py` (склейка 4 скриншотов по совпадающим подписям из `labels.py`/`fit2.py`) → `seg.py`/`seg2.py` (помещения, коридоры, островки по цвету заливки) → `gen4.py` (названия, присоединение безымянных помещений к магазинам без выхода в коридор, расширение коридоров на ~30%, выпрямление стен по трём семействам направлений, проёмы, колонны только в атриумах, эскалаторы из центров атриумов с проходом ≥2 м, входы) → `repair.py` (связность) → `preview.py`. Координаты подписей в `labels.py` сняты вручную со скриншотов. Результат детерминирован.

## Проверенные ловушки

- Режим `store` должен использовать `walkPose()`. Иначе камера улетает в вид сверху и в магазине виден белый экран.
- Атрибут `hidden` работает только вместе со сбросом `[hidden]{display:none!important}` (он есть в `style.css`).
- Проём двери в маске проходимости прорезан через `setRect`. Без этого в магазин не войти.
- Не освобождай общие материалы (`MAT.*`) и текстуры (`marble`, `shelfAtlas`) в `disposeShop`.
- В headless Chromium (swiftshader) кадр рисуется медленно, а `dt` ограничен 0.05 с. В тестах телепортируй игрока через `__maxi`, а не «иди клавишами», и жди `!__maxi.anim` перед скриншотом.
- Двери, люди и подписи вида сверху — у каждого этажа свои. Новые объекты второго этажа клади в группу `f2`/`slab`, иначе в виде сверху первого этажа они будут висеть в воздухе.
- Всё, что зависит от этажа, проверяй через `d.floor`/`s.floor` и `curFloor`: вход в магазин и открытие дверей идут только на текущем этаже.
