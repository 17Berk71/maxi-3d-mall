# Как устроен сайт «Прогулка по Макси»

Код разложен по небольшим модулям: каждый файл отвечает за одну часть сайта. Полный список файлов с описанием и тем, что каждый отдаёт другим, — в `docs/modules.md` (создаётся командой `node tools/docs/modules.mjs > docs/modules.md`).

## Папки `src/`

| Папка | За что отвечает |
|---|---|
| `main.js`, `app.js` | Вход: Vite запускает `main.js` (шрифты, стили, данные карты) → `startApp(D, D2)` в `app.js`, который по порядку вызывает `init()` модулей. |
| `core/` | Запуск (`start.js`), главный цикл (`loop.js`), общее состояние (`state.js`), настройки посетителя (`settings.js`), шрифты, мелкие помощники, отладочный доступ `window.__maxi` (`debug.js`). |
| `render/` | Рендерер и сцена галереи, текстуры и атласы вывесок, склейка геометрии (`merger.js`), эффекты (`fx.js`: отражение пола, свечение, цвет), пробные стили (`styles.js`), отражение пола без второго прохода (`floor-mirror.js`). |
| `nav/` | Сетка проходимости обоих этажей (`walkgrid.js`), перелёты и «подойти к двери» (`travel.js`), проверка карты (`audit.js`). |
| `mall/` | Галерея: категории и список магазинов, мир (группы сцены, высоты, материалы, двери), лифты и эскалаторы (поездки), посетители, вывески (`signs.js`). |
| `mall/build/` | Сборка 3D-сцены галереи по частям: пол, фасады помещений (`fronts.js`), двери, второй этаж, крыша, ограждения, колонны, светильники, фасад, эскалаторы, островки, лифты, кадки и лавочки, посетители, колесо. Порядок — в `mall/build.js`. |
| `controls/` | Игрок и камера (`player.js`), вид сверху (`view.js`), ходьба и этажи (`move.js`), ввод: мышь, касания, джойстик, клавиатура (`input.js`). |
| `ui/` | Выбор под курсором, карточка магазина, фильтр, поиск, мини-карта, большая карта, «Перейти сюда», настройки, подсказки. |
| `shop/` | Магазины изнутри: зал (`hall.js`), свет и декор, покупатели, вход и выход, панель каталога, страница товара, корзина; данные каталога (`catalog.js`, `feeds.js`, `online.js`, `describe.js`, `models.js`, `interiors.js`, `photos.js`, `icons.js`, `cart.js`). |
| `shop/fitting/` | Примерочная. Вход для остального сайта — `shop/fitting.js` (отдаёт `createFitting` и функции для проверок). |
| `data/`, `assets/`, `style.css` | Данные карты обоих этажей, фото товаров, стили интерфейса. |

### Примерочная (`shop/fitting/`)

| Что | Файлы |
|---|---|
| Что за вещь, размеры | `classify.js`, `sizes.js`, `specs.js` (мерки по фото), `measures.js` (мерки верха для выкройки) |
| Фигура | `body.js` (мерки → размеры тела), `mannequin.js` (видимый манекен), `paint-body.js` |
| Выкройка | `pattern.js` (детали, рукава, пресеты ткани `FABRIC`), `drape.js` (вещь целиком: верх, юбка, брюки), `collars.js` (стойка, капюшон), `shoulder-round.js` (плечевая точка без угла) |
| Расчёт ткани | `collider.js` (тело для столкновений), `sim.js` (`runCloth`, движение для анимации), `worker.js` (фоновый поток, `CLOTH_VER`), `cache.js` |
| Показ | `cloth-mesh.js` (сетка, нормали, заломы), `pleats.js` (складки плиссе формой, сглаживание юбки, нижний слой-подклад), `decor.js` (пуговицы — объёмные детали на ткани), `cloth-material.js` (ткань как материал, шейдер), `photo-texture.js` (фото без своей светотени, ровная ткань для плиссе) |
| Вещь целиком | `garment-async.js` (выкройка → расчёт → сетка), `garment.js` (синхронно, запасной путь), `qc.js` (автопроверка) |
| Окно примерочной | `ui.js` → `room-*.js`: гардероб, сцена кабины, сборка образа, проигрывание анимации, панель, ползунки фигуры, открытие окна, пакеты примерки, API (`FIT`) |
| Прежние способы | `simple-garment.js` + `fabric-simple.js` (простые формы, `?drape=0`), `photo-garment.js` (вещь из фото поверхностью), `drape-old.js` (первый прототип ткани) |

## Как модули связаны

- **Импорты.** Модуль берёт у другого функции и переменные через `import`. Функции доступны сразу; переменные, которые заполняются в `init()`, читаются уже во время работы (живая привязка ES-модулей), поэтому круговые импорты между модулями допустимы.
- **Порядок запуска.** `startApp` вызывает `init()` модулей строго в том порядке, в каком они перечислены в `app.js` (так же `mall/build.js` для частей сборки и `shop/fitting/ui.js` для окна примерочной). Модуль может опираться на то, что подготовили модули выше. Новый модуль с подготовкой при запуске — добавить его `init()` в нужное место списка.
- **Общее состояние.** Переменные, которые меняют несколько модулей (этаж, режим, текущий магазин…), лежат в одном объекте: `app` (`core/state.js`) для галереи и `fit` (`shop/fitting/state.js`) для примерочной. Список полей с пояснениями — в начале этих файлов. Остальное у каждого модуля своё.
- **Данные карты.** `D` (первый этаж) и `D2` (второй) — параметры `startApp`, модули берут их `import {D, D2} from '../app.js'`.
- **Фоновый поток.** Код расчёта ткани в Web Worker собирается из самих функций (`toString`) — список в `shop/fitting/worker.js` (`torsoR, sx, sz, armRad, armX, armJ, legR, makeCollider, motionAt, runCloth`). Функции, которые они вызывают, должны быть в этом списке.

## Инструменты (`tools/`)

- `tools/pipeline/` — карта этажей из скриншотов (`npm run map`, `npm run map2`).
- `tools/feeds/` — выгрузки товаров магазинов (`import_feed.py`), пакеты примерки (`fitpack.py`), размеры (`sizes.py`), бренды.
- `tools/wardrobe/` — фабрика вещей из фото: `build.py` (порядок шагов и запуск) → `photo_io.py` (чтение фото), `cutout.py` (вырезание из фона), `parts_top.py` / `parts_bottom.py` (части и мерки), `drape_cut.py` (выкройка для расчёта ткани, молния, пуговицы), `color_balance.py`, `model_photo.py` (фото на человеке), `seg_person.py` (нейросеть), `debug_view.py`, `wardrobe_paths.py`, `items.py` (список вещей). Автопроверка — `tools/wardrobe/qc/`.
- `tools/test/check.mjs` — проверка сайта в браузере (`npm run check`).
- `tools/docs/modules.mjs` — карта модулей (`docs/modules.md`).
- `tools/deploy/` — выкладка в Яндекс Object Storage.
